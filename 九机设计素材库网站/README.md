# 九机设计素材库

九机设计素材库 - Design Assets Library（公共云端版）

## 功能

- 🎨 素材上传与管理（AI/PSD/EPS 源文件）
- 👥 多人共用，数据云端存储
- 🔐 邮箱注册/登录
- 🌐 素材广场（分享给团队）
- ❤️ 收藏功能
- 🖼️ Banner 轮播管理

## 技术栈

- **前端**：原生 HTML/CSS/JavaScript
- **后端**：Firebase（Auth + Firestore + Storage）
- **托管**：GitHub Pages（免费）
