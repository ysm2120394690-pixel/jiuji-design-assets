- ✅ **免费额度充足** - Firebase 免费套餐适合中小型团队

## 第一步：创建 Firebase 项目

详细步骤请参考 `FIREBASE_SETUP.md`，简要步骤：

1. 访问 https://console.firebase.google.com/ → 创建项目
2. 注册 Web 应用 → 复制 `firebaseConfig`
3. 启用 **Authentication**（邮箱/密码登录方式）
4. 创建 **Firestore Database**（测试模式）
5. 启用 **Storage**（存储）

## 注意事项

### 安全性
⚠️ `firebase-config.js` 包含您的 Firebase 配置密钥，**不要提交到公开代码库**！

**推荐做法**：创建 `.gitignore` 排除此文件，部署时单独配置：

```
# .gitignore
firebase-config.js
```

### Firestore 安全规则（重要）

生产环境请在 Firebase Console → Firestore → 规则中设置：

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 用户数据：只能读写自己的
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
    // 素材：所有人可读，登录用户可创建，作者可编辑/删除
    match /assets/{assetId} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null && request.auth.uid == resource.data.ownerId;
    }
    // Banner：所有人可读，登录用户可管理
    match /banners/{bannerId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    // 收藏：只能管理自己的
    match /favorites/{userId}/items/{assetId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

## 快速问答

**Q: 已有 GitHub 账号可以直接用吗？**
A: 可以，只需创建新仓库即可。

**Q: 不想用 GitHub Pages 怎么办？**
A: 可以用 Vercel（`vercel.com`）或 Netlify（`netlify.com`），关联 GitHub 仓库自动部署，更快更简单。

**Q: 数据存在哪？**
A: Firebase（Google 云服务），数据安全可靠，不会丢失。

**Q: 多人同时上传会冲突吗？**
A: 不会。Firestore 自动处理并发，数据不会冲突。
